## 一键安装（中文）

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/freekm-dev/3x-ui/master/install-cn.sh)
```

安装脚本全程中文提示，自动完成：

```
检测系统 → 展示系统配置并确认 → 安装依赖 → 选择数据库/证书
        → 下载安装包 → SHA256 校验 → 安装服务 → 生成随机凭据
        → 配置证书 → 按需放行防火墙 → 展示访问信息与加固建议
```

> 脚本会**先展示当前系统配置（系统版本 / 内核 / CPU / 公网 IP / SSH 端口）并等待你确认**
> 输入 `y` 才继续安装；输入其它键直接退出，**不会对系统做任何改动**。

## 为什么用这个仓库

官方项目一直在更新。本仓库把安装所需的全部资源（二进制包、服务文件、Geo 数据）保存到**自己的 Release**，安装脚本的所有下载地址都指向本仓库，因此：

- **即使官方仓库消失，安装依然可用**
- 安装过程**不再访问任何 mhsanaei 地址**
- 中文提示，对新手更友好

## 安全特性

- **随机凭据**：安装时自动生成随机的用户名、密码、面板端口、访问路径，避免默认弱口令
- **完整性校验**：下载后自动校验 SHA256，防止篡改
- **智能防火墙**：按你的选择精确放行（详见下方），443 端口永久保留
- **隐藏入口**：面板使用随机访问路径，直接访问根路径返回 404
- **SSH 保护**：安装前检测 SSH 端口是否放行，避免配置后再也连不上

安装完成后脚本会给出进一步加固建议（SSH 密钥登录、fail2ban 等）。

## 防火墙规则说明

脚本会**先检测你是否有正在运行的 SSH 服务**，并据此提示。端口放行规则如下：

| 端口 | 何时放行 |
| --- | --- |
| **443** | **永远放行**（保留给你后续自配的 HTTPS 服务，如 Xray TLS 回落；面板本身不用 443） |
| **面板端口** | 选「域名证书 / IP 证书 / 自有证书」时放行；选「不加证书（隧道）」时**不放行** |
| **80** | 仅选「域名证书 / IP 证书」时放行，用于证书签发验证 |

> 所有防火墙改动都**在安装完成后统一执行**。若你在确认步骤选择退出，防火墙不会有任何改动。
> 未检测到 SSH 服务时（如通过 VNC / 物理终端操作），脚本会跳过 SSH 端口检查，不会误报。

## 证书方式说明

安装时可选四种证书方式：

| 选项 | 说明 | 有效期 |
| --- | --- | --- |
| 1 域名证书 | 需要你有域名，自动申请并自动续期 | 90 天 |
| 2 IP 证书 | 用服务器 IP 申请，无需域名 | 约 6 天（自动续期） |
| 3 自有证书 | 你已有证书文件，填路径即可 | 自定义 |
| 4 不加证书 | 面板走 HTTP，**仅适合 SSH 隧道访问** | — |

## 管理命令

```bash
x-ui                      # 打开管理菜单
systemctl status x-ui     # 查看服务状态
systemctl restart x-ui    # 重启面板
journalctl -u x-ui -f     # 查看实时日志
```

安装凭据保存在：`/etc/x-ui/install-result.env`

## 通过 SSH 隧道访问（推荐）

如果你不想把面板端口直接暴露到公网，可以用 SSH 本地端口转发，只有你自己能访问：

```bash
# 把本机端口映射到服务器的面板端口
# 面板端口在安装完成时会显示，形如 35201
ssh -L <面板端口>:127.0.0.1:<面板端口> root@你的服务器IP -p 你的SSH端口

# 例如面板端口是 35201、SSH 端口是 22：
ssh -L 35201:127.0.0.1:35201 root@149.28.198.109 -p 22
```

建立隧道后，在本机浏览器访问：

```
http://127.0.0.1:<面板端口>/<你的访问路径>
```

> 走隧道时，面板**无需对公网放行端口**，安全性最高——攻击面只剩 SSH 本身。
> 若同时想用面板管理 Xray 节点流量，把隧道端口设成你节点的入站端口即可。
> 安装脚本在检测到 SSH 服务时，会在结尾**自动生成对应的隧道命令**，直接复制即可。
